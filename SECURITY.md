# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through **GitHub → Security → Report a vulnerability** on this repository. Do not open a public issue.

Include the affected component, steps to reproduce and the impact. You will get an acknowledgement within 3 working days. Please allow up to 90 days for a fix before public disclosure.

## Scope

In scope: the app in this repository, the database schema, its policies and RPCs, and the Edge Functions.
Out of scope: the Supabase, Expo and GitHub platforms themselves (report those to the vendors), denial-of-service through volume, and social engineering.
